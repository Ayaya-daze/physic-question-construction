# 实施计划

## 开发原则

先完成稳定的文件题库闭环，再逐步加入 OCR、LLM 和复杂检索。

当前主线：

1. 文件存题。
2. 浏览器看题。
3. 文件索引。
4. 搜索。
5. 组卷。
6. TeX/PDF 导出。

## Phase 1: 文件题库 MVP

目标：题目文件能被可靠保存、读取、展示和索引。

任务：

- [x] 定义 `questions/{id}/question.*`、`answer.*`、`assets/*`。
- [x] 实现文件题库读取 API。
- [x] 实现文件题库上传/创建 API。
- [x] 实现题目列表页。
- [x] 实现题目详情页。
- [x] 前端支持 LaTeX 数学公式渲染。
- [x] 前端支持图片资产显示。
- [x] 实现本地索引重建。

验收：

- `/questions` 能列出题目文件。
- `/questions/{id}` 能显示题目、答案、图片和公式。
- `/api/file-questions/reindex` 能重建索引。

## Phase 2: 基础组卷与导出

目标：把题库中的题目文件拼成试卷，分别输出题目卷和答案卷 TeX/PDF。

任务：

- [x] 实现文件题库组卷 API。
- [x] 支持手动传入题目 ID。
- [x] 支持搜索词/知识点 + 题目数自动选题。
- [x] 复制题目图片资产到导出目录。
- [x] 生成只含题目的 `questions.tex`。
- [x] 调用 XeLaTeX 编译 `questions.pdf`。
- [x] 生成只含答案的 `answers.tex`。
- [x] 调用 XeLaTeX 编译 `answers.pdf`。
- [x] 分别保存 `build-questions.log` 和 `build-answers.log`。
- [x] 前端 `/papers` 提供浏览器组卷页面。
- [x] 前端分别显示题目卷和答案卷 TeX/PDF/日志下载链接。

当前验收状态：

- 当前文件题库导出主路径已生成题目卷和答案卷两套独立产物。
- 旧兼容字段可以保留，但新功能应继续使用题目卷和答案卷的独立下载链接。

验收：

- 用户可以在浏览器输入标题、搜索词、题目数。
- 用户可以手动勾选题目。
- 导出结果分别包含题目卷和答案卷。
- 含图题目的 PDF 中能看到题图。
- 编译失败时仍能拿到对应 TeX 和日志。

## Phase 3: 导入增强

目标：从外部资料生成文件题目候选。

任务：

- 支持 Markdown/LaTeX/TXT 直接导入。
- 支持 PDF/图片页面渲染。
- 支持多模态 LLM 直接读取页面图片并整理题目正文和答案正文。
- 支持 OCR 作为辅助 hint，而不是扫描件的生产真源。
- 支持人工审核后写入 `questions/{id}/`。
- 保存原始文件、OCR 输出和 LLM 输出。
- PDF 没有可靠文本时，不写入正式题库；整页页面渲染图只作为识别/审核证据，不能作为题目正文或组卷内容。
- OCR/LLM 产出可靠 Markdown/LaTeX 文本时，正文保存文本，图片只在需要处引用。
- 不把 PDF 抽取出的损坏 Unicode 数学文本当成生产正文。
- 不把 CnOcr + text-only LLM 作为扫描物理试卷的生产级自动导入路径。

## Phase 4: 检索增强

目标：提升题目召回质量。

任务：

- 接入真实 embedding 模型。
- 支持 pgvector 或 Qdrant。
- 实现 hybrid search。
- 实现相似题和重复题提示。

## Phase 5: LLM 辅助组卷

目标：自然语言辅助组卷，但最终题目仍来自题库文件。

任务：

- 解析自然语言需求为搜索词、题目数和约束。
- 给出候选题解释。
- 建议替换题。
- 不生成题库外题目作为正式结果。

## 技术风险

### OCR 准确率

风险：

- 公式识别差。
- 题图和文字关系错乱。
- 题目边界切错。
- OCR 可能漏掉可见题号。
- OCR 可能把页面噪声误读成题号。
- text-only LLM 可能改写结构并破坏题目边界。

应对：

- 使用多模态模型直接读取页面图片。
- 保留原始截图。
- 进入人工审核。
- 先生成可编辑题目文件。

### LLM 幻觉

风险：

- 编造答案。
- 改写题意。
- 错误打标签。

应对：

- LLM 输出只作为候选。
- 保留原文。
- 人工确认后入库。

### LaTeX 编译

风险：

- 用户题目里有不完整 TeX。
- 图片格式不被当前引擎支持。
- Markdown 转 TeX 不覆盖所有语法。

应对：

- 导出失败保留对应的 TeX 和编译日志。
- 前端分别显示题目卷和答案卷日志入口。
- 后续增强转换器和模板。
