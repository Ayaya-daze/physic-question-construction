# 题目导入模板说明

## 模板文件

导入模板支持 **Excel (.xlsx)** 和 **CSV (.csv)** 两种格式。推荐使用 Excel 格式，以避免编码问题。模板第一行为列名（表头），从第二行开始为题目数据。每行代表一道题目。

## 字段说明

| 列名 | 必填 | 类型 | 说明 | 示例 |
|------|------|------|------|------|
| `question_type` | 是 | 字符串 | 题目类型，必须使用枚举值 | `选择题` |
| `stem` | 是 | 字符串 | 题干内容，支持 LaTeX 公式 | `一物体做匀加速直线运动，初速度为 $v_0=2\\,\\text{m/s}$，加速度为 $a=3\\,\\text{m/s}^2$，求 4 秒末的速度。` |
| `option_a` | 否 | 字符串 | 选项 A 内容（选择题/判断题必填） | `$6\\,\\text{m/s}$` |
| `option_b` | 否 | 字符串 | 选项 B 内容（选择题必填） | `$10\\,\\text{m/s}$` |
| `option_c` | 否 | 字符串 | 选项 C 内容（选择题必填） | `$12\\,\\text{m/s}$` |
| `option_d` | 否 | 字符串 | 选项 D 内容（选择题必填） | `$14\\,\\text{m/s}$` |
| `answer` | 是 | 字符串 | 正确答案，格式取决于题目类型 | `D` |
| `answer_type` | 是 | 字符串 | 答案类型 | `字母选项` |
| `solution` | 否 | 字符串 | 解析或解题过程，支持 LaTeX | `由公式 $v=v_0+at$ 得：$v=2+3\\times4=14\\,\\text{m/s}$，故选 D。` |
| `knowledge_points` | 否 | 字符串 | 关联知识点，多个用分号分隔 | `匀变速直线运动的速度公式;加速度的概念` |
| `tags` | 否 | 字符串 | 标签，多个用逗号分隔 | `力学,运动学,典型题` |
| `difficulty` | 是 | 整数 | 难度等级 1-5 | `2` |
| `score` | 否 | 数值 | 题目分值 | `5` |
| `grade` | 否 | 字符串 | 适用学段（自由文本） | `本科力学`, `大学本科`, `竞赛` |
| `textbook_version` | 否 | 字符串 | 教材版本（自由文本） | `University Physics (Young)`, `自编讲义`, `课程讲义` |
| `chapter` | 否 | 字符串 | 所属章节 | `运动学`, `Lagrangian Mechanics`, `Quantum States` |
| `source_title` | 否 | 字符串 | 题目来源（如试卷名称） | `力学专题练习册` |
| `source_page` | 否 | 字符串 | 来源页码或题号 | `第 3 题` |

## 题型枚举值

| 枚举值 | 中文名称 | 说明 |
|--------|----------|------|
| `选择题` | 选择题（单选） | 四个选项，一个正确答案 |
| `多选题` | 多选题 | 四个或更多选项，至少两个正确答案 |
| `判断题` | 判断题 | 判断命题正误，通常选项为 A（正确）B（错误） |
| `填空题` | 填空题 | 在空白处填写答案 |
| `计算题` | 计算题 | 需要列式计算的大题 |
| `简答题` | 简答题 | 需要文字叙述回答的题目 |
| `实验题` | 实验题 | 考查实验原理、操作、数据分析等 |
| `作图题` | 作图题 | 需要绘制图表、图像等 |
| `综合题` | 综合题 | 包含多个小问的综合性大题 |

## 难度等级

| 等级 | 名称 | 说明 | 适用场景 |
|------|------|------|----------|
| 1 | 基础 | 直接考查单一公式或概念的简单应用 | 课堂练习、入门检测 |
| 2 | 较易 | 考查单个知识点的简单变式 | 课后作业、单元小测 |
| 3 | 中等 | 需要综合 2-3 个知识点的典型题 | 阶段测验 |
| 4 | 较难 | 需要灵活运用多个知识点或复杂数学模型 | 综合练习压轴题 |
| 5 | 高难 | 创新型或竞赛类题目，需要深度分析和创造性思维 | 竞赛选拔、培优训练 |

## 知识点路径格式

知识点采用层级路径表示法，各级之间用 `/` 分隔，格式为：

```
学段/一级领域/二级主题/具体知识点
```

**示例：**

- `力学/牛顿运动定律/牛顿第二定律`
- `电磁学/恒定电流/欧姆定律`
- `热学/分子动理论/理想气体状态方程`
- `光学/几何光学/折射定律`

**注意事项：**

- 路径层级建议不少于 3 级（领域/主题/知识点）
- 多个知识点用分号（`;`）分隔，分别填写完整路径
- 如果导入文件中的知识点路径在现有知识图谱中不存在，系统会自动创建**候选知识点**，待人工审核后加入正式知识图谱；无需预先配置知识点树。
- 知识点路径应与学科知识体系一致，便于后续按知识点检索

## 注意事项

1. **编码格式**：CSV 文件请使用 **UTF-8 BOM** 编码保存，否则中文字符在 Excel 中打开可能出现乱码。Excel (.xlsx) 文件无需担心编码问题。

2. **LaTeX 公式**：题干、选项和解析中的数学公式请使用 `$...$`（行内公式）或 `$$...$$`（块级公式）包裹。为保证 CSV 兼容性，公式内的反斜杠请双写（如 `\\frac{1}{2}`）。

3. **逗号处理**：如果单元格内容包含逗号（如 CSV 格式），请用英文双引号将该字段包裹起来，避免与分隔符冲突。Excel 格式会自动处理此问题。

4. **答案格式**：选择题和多选题的答案字段填写选项字母（如 `A`、`D`、`ABD`）；判断题填写 `A`（正确）或 `B`（错误）；填空题、计算题直接填写答案内容。

5. **必填字段**：`question_type`、`stem`、`answer`、`answer_type`、`difficulty` 为必填字段，缺失将导致该行数据导入失败。

6. **唯一性校验**：系统会根据题干内容自动去重。如果导入的题目与题库中已有题目高度相似，将被标记为疑似重复，需人工确认后导入。

7. **难度一致性**：请根据难度等级定义合理设置。标注难度与实际题目难度严重不符的，系统会在导入后提示复核。

8. **知识点匹配**：知识点路径应使用系统中已建好的知识点树中的路径。如果导入了系统不存在的知识点路径，系统会自动创建新的知识点节点，但建议导入前先在系统中确认知识点体系是否完整。
