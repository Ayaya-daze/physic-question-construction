# 产品需求与路线图

## 一句话定位

一个文件优先的物理题库系统：以题目文件和答案文件为真源，支持浏览器查看、搜索、向量索引、组卷和 TeX/PDF 导出。

它不是固定题型数据库，也不是靠 LLM 临时生成试卷。第一阶段先保证真实可用：题目能存、能看、能搜、能拼成卷、能导出。

## 目标用户

- 物理教师/讲师：整理题目、备课、组练习卷。
- 教研/课程团队：维护题库文件、题图资产、知识点标签和模板。
- 学生/自学者：按关键词或知识点生成练习。
- 个人资料整理者：把已有 PDF、扫描件、讲义和笔记整理成可检索题库。

知识范围由用户导入的材料决定，不绑定特定学段、教材或预设课程树。

## 核心使用场景

### 1. 文件题库录入

每道题以目录存储：

```text
questions/{question_id}/
  question.md | question.tex | question.txt
  answer.md   | answer.tex   | answer.txt
  assets/
  metadata.yaml
```

核心只要求题目正文和答案正文。选择题选项、小问、解析、实验材料等内容直接写在正文或答案中，不拆成硬编码字段。

### 2. 浏览器查看与人工维护

前端应能：

- 列出题目文件。
- 搜索题目正文、答案和可选元数据。
- 显示题目正文、答案、图片资产。
- 渲染 LaTeX 数学公式。
- 显示索引状态。

### 3. OCR/LLM 辅助导入

OCR 和 LLM 的目标不是直接写复杂 JSON，而是辅助生成或修正：

- `question.*`
- `answer.*`
- `assets/*`
- 可选 `metadata.yaml`

识别结果默认需要人工审核，不能无确认污染正式题库。

### 4. RAG 检索与相似题

系统支持：

- 关键词检索。
- 本地或外部向量检索。
- 根据自然语言需求找候选题。
- 相似题和重复题提示。

向量库只保存可重建索引，不保存唯一真源。

### 5. 基础组卷

用户输入：

- 可选手动选题。
- 相关知识点或搜索词。
- 题目数。
- 可选 LLM/搜索辅助。
- 卷面结构信息，例如题目数。

系统输出：

- `questions.tex`
- `questions.pdf`
- `answers.tex`
- `answers.pdf`
- `assets/`
- 题目卷和答案卷各自的编译日志。

组卷实现就是把题目正文转换或原样拼入题目卷 LaTeX 模板，把答案正文转换或原样拼入答案卷 LaTeX 模板，并复制图片资产。题目和答案不能混在同一个 PDF 里作为最终交付结果。

如果题目正文已经是 OCR/LLM 整理后的 Markdown/LaTeX 文本，导出必须使用这些文本生成 TeX。扫描 PDF 的整页渲染图不能作为降级正文进入 TeX 模板；只有独立题图或从页面裁剪出的题图资产才能进入组卷。

### 6. LLM 辅助组卷

LLM 可以做：

- 解析自然语言需求。
- 扩展搜索词。
- 解释候选题匹配原因。
- 建议替换题。

LLM 不能绕过题库直接把原创题伪装成题库题。

## 非目标

第一阶段不做：

- 固定题型枚举驱动的题库主模型。
- 强制拆分选项、答案类型、解析步骤、多小问表。
- 完全无人审核的 OCR/LLM 入库。
- 大规模 SaaS 多租户。
- 复杂学习诊断。

旧结构化数据库可以作为兼容层或导入实验，不作为当前生产主路径。

## MVP 成功标准

- 可以用文件目录保存题目、答案和图片。
- 可以在浏览器中查看题目、答案、图片和 LaTeX 公式。
- 可以从题目文件重建索引。
- 可以搜索题目正文、答案和元数据。
- 可以手动选题或按搜索词/知识点自动选题。
- 可以分别生成题目卷和答案卷 TeX 源文件。
- 本机有 LaTeX 环境时可以分别编译题目卷和答案卷 PDF。
- 含图题目的导出 PDF 中能看到题图。

## 路线图

| 阶段 | 名称 | 主要目标 |
| --- | --- | --- |
| 1 | 文件题库 MVP | 文件存储、浏览器查看、公式/图片渲染 |
| 2 | 索引与搜索 | 文件索引、关键词和向量检索 |
| 3 | 基础组卷 | 选题、搜索补齐、TeX/PDF 导出 |
| 4 | 导入增强 | OCR/LLM 辅助生成题目文件 |
| 5 | RAG 增强 | 相似题、重复题、自然语言检索 |
| 6 | LLM 辅助组卷 | 需求解析、候选解释、替换建议 |
